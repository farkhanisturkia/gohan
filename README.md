## About Gohan

Gohan is a web application framework with lightweight, fast, and structured Go fullstack ecosystem integrated with Vue 3, Tailwind CSS, and TanStack Query.

## Getting Started

### 1. Install Go

Follow the official installation guide on the <a href="https://go.dev/doc/install">Go Website</a>.

### 2. Install Node.js & NPM

Follow the official installation guide on the <a href="https://nodejs.org/en/download">Node</a>.

### 3. Install Gohan CLI

```bash
go install github.com/farkhanisturkia/gohan/cmd/gohan@v1.8.5
```

### 4. Basic CLI Usage

Check available commands and options:
```bash
gohan -h
```

Check installed Gohan CLI version:
```bash
gohan -v
```

Create a new Gohan project:
```bash
gohan init
```
